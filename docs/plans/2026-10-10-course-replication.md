# 原论文课程复现与素材包执行计划 v1.1

**Goal:** 完成 I20/R20 单配置的五成员训练复现、原文结果对照及解释，交付可支撑3–4页/约3分钟的最终素材包。

**Architecture:** 复用已经验收封存的五成员与集成结果，新增工作基于已核验聚合CSV/JSON；不改历史训练、输入或指标原值。动态状态只在[主控](2026-09-10-foundation.md)维护。

**Tech Stack:** 自有PyTorch训练证据、CSV/JSON、PNG/SVG、离线HTML/Markdown与ZIP。

## 本次调整与执行规则

2026-10-10用户要求根据已获数据只有I20/R20重新调整，并明确：**里程碑是检查点，只做简短进度汇报，不作为停工等确认节点。** 本规则直接同步，优先于历史每Gate等待规定。范围内正常通过后立即继续；真实权限、重大未决语义/协议、预算突破或非预期执行失败仅暂停受影响工作，其他可独立工作继续。不得因普通检查点反复请求同范围许可。

原v1六组单成员方案因缺对应完整输入退出本次必做范围，九组不再是本次交付依赖；旧方案与审计保存在 `artifacts/course-replication-v1/scope-v11/`。本次主线为**一组配置×五次独立训练×分类/排序/经济结果对照**。不把换标签、裁图或截尾缓存当其他配置，不在剩余时间无限搜索数据。

只聚焦第一篇原论文的代码复现；其他同学负责论文背景/设计等汇报。没有教师硬性转债要求，本次不做转债、国际迁移、解释性或全套CNN1D/Linear；不比较其他同学仓库，不制作PPT，只提供有余量的素材。

## 怎样衡量复现程度

| 任务 | 必须回答 | 交付与标准 |
|---|---|---|
| 方法与工程链路 | 实际复现哪些步骤，与原文设定有何差异？ | 输入、年份/样本、split/norm、CNN、优化器、早停、五成员集成及证据来源对照表 |
| 同配置原文比较 | I20/R20的排序和经济结果接近到什么程度？ | Table II D1–D10及H-L年化算术收益/SR与差值；月频turnover独立行 |
| 随机性与集成 | 单成员表现波动多大，平均概率后的效果怎样？ | 全部五成员、均值/样本std(ddof=1)/min/max及ensemble独立列；不择优成员 |
| 分类解释 | 53%左右准确率是否超过合理参照？ | always-up/down、上涨占比、BA/AUC/CE/Brier与混淆矩阵；概率0.5常量CE/Brier可作明确分析参照 |
| 经济解释 | 排序收益、EW/VW和训练过程怎样解读？ | 十分位、H-L、收益/波动/换手、训练曲线、时间序列；权重敏感性，不宣称规模因果效应 |
| 交付与边界 | 能讲什么、不能讲什么，能否独立读取材料？ | 3–4页取舍、3分钟讲述素材、额外图/CSV/SVG/问答、来源和限制、ZIP检查 |

主比较为原文Table II的I20/R20 EW H-L SR **2.16**，原文H-L年化算术收益 **0.21**、月频turnover **1.73**。直接录原文H-L行，不能由已舍入D10-D1反算。自己的对应值与原文差值只作描述性比较，不设任意接近阈值或必须盈利的PASS标准。原文未取得的分类指标/月频VW数值不编造；原文MOM/STR等属于文献参照，不能称本项目同样本重跑基线。

各成员split、归一化与初始化不同，五成员离散统计是这些随机因素的联合波动，**不是置信区间、五次独立OOS试验或跨配置稳健性**。未来单成员复用判据不再是本次必做；直接展示已经封存的全部五成员和集成，不追加种子/调参/阈值选择。

## 可追溯边界

采用作者已生成图像，仅复现成品图像→独立CNN/训练→预测/组合分析；不称原CRSP到图像全链路重建。1993–2000开发池内每成员固定70/30随机split，2001–2019历史评价保持时间隔离，不随机混合训练与评价。实际评价1,387,781行、227个月，2019只有11个月。

保留Ret_month proxy、缺作者next_month_ret sidecar、endpoint未验证、已见OOS和未扣交易成本。年化收益为月均×12，波动为样本std×√12，SR为二者比值；累计H-L直接求和，不是净值。旧AUC/Spearman tie口径与float32/64阈值差保留为技术说明，不覆盖历史值，不占据展示主叙事。

新分析只读取r2已验证聚合CSV/JSON及精选receipt，记录父文件SHA和新增计算；不新训练、不推理、不解码原始OOS，不复制/执行参考代码。普通实现由主Agent完成；路线实质调整与新增分析正式验收使用已有研究/工程独立及交叉审阅，不重复委派普通工作。

## 检查点与连续推进

1. **M1 范围/证据核对**：落本v1.1、主控、ADR/迁移地图和README；独立审阅后简短汇报，继续M2。
2. **M2 补齐可比较素材**：原文11行经济对照+turnover；五成员离散统计；设定差异表；分类参照。对账后简短汇报，继续M3。
3. **M3 解释与正式复核**：结论只落在单配置、同样本成员比较和权重敏感性；新增分析独立/交叉验收，修正文案，继续M4。
4. **M4 最终交付**：最终单配置素材包r3，附PNG/SVG、CSV/JSON、离线报告、素材说明和精选证据；manifest/CRC/SHA/链接/视觉检查通过后交付，无需等普通里程碑确认。
