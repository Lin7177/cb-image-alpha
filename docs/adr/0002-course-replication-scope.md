# ADR 0002：依据可得输入完成单配置五成员课程复现

2026-10-10 v1.1决定（当前，ACCEPTED / ROUTE_FROZEN）：研究/工程同版独立及双向交叉审阅通过，无分歧。用户要求根据只有I20/R20的可得输入调整思路；核心由六组单成员转为I20/R20五成员与ensemble、Table II完整经济对照、成员离散/分类基线/EWVW解释及最终素材包。其余八格退出本次交付依赖。原v1审计/快照保留，不改历史实验PASS。五成员联合随机波动不是CI，不以现有页数足够为完成标准；具体可比较素材仍须补齐验收。

用户明确里程碑只做简短进度汇报，不停工等确认；正常核验通过后连续推进。总预算沿用10h上限和已有扣账，不新增无必要训练。当前状态见主控，执行细节见课程计划v1.1。

## 历史v1六组决定（已被v1.1取代）

日期：2026-10-10。状态：ACCEPTED / ROUTE_FROZEN。用户同意，研究/工程独立及双向交叉审查通过；具体训练协议尚未冻结。审计记录见 `artifacts/course-replication-v1/route-audit-20261010.json`。

用户负责第一篇原论文的代码复现模块，需约 3–4 页/3 分钟素材；距汇报约 72h，追加机器运行上限 10h。既有九组×五成员长期目标与这次作业资源不匹配，但不能因此认定已有单格足够。

决定：优先 I{5,20,60}×R{5,20} 六组，固定首成员，先完成月频窗口轴再周频；R60 仅在完整输入、六组完成及预估预算满足时扩展，与结果好坏无关。既有五成员 I20/R20 单列补充；旧 member-0 复用须逐项匹配。核心比较采用原文 Table I/II EW H-L SR，辅以十分位、VW、收益/波动/换手和分类基线。

旧科研/转债路线及冻结运行不删除、不重写；新课程命名空间与入口独立，主控唯一维护动态状态。当前缺失八组输入是执行风险，先有界核查公开来源；不能换标签/缩放图像/使用截尾缓存填格。输入不足允许交付受阻进度素材，不冒称六组完成。

用户已授权本次路线依前置条件连续推进；完整可执行协议仍须双独立交叉审计后才训练。没有输入时不建训练代码凑进度；不为课程展示追求严格科研级未见测试，也不抹去已见 OOS 和 endpoint/proxy 限制。
